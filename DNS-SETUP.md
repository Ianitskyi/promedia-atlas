# Підключення atlas.promedia.report

Сайт опубліковано для приватного перегляду: https://promedia-atlas.ianitskyi.chatgpt.site

Піддомен додано до Sites. Очікується підтвердження DNS. У Cloudflare для зони promedia.report потрібно додати наведені записи, попередньо перевіривши відсутність конфліктного запису atlas.

| Тип | Ім’я | Значення |
| --- | --- | --- |
| CNAME | atlas | custom-domains.chatgpt.site |
| TXT | _openai-site-verification.atlas | openai-site-verification=xSrQVoEPg63_EALmmH6Iu3t1l9lC2zDJVPAM-Qf8vZY |
| TXT | _cf-custom-hostname.atlas | 2249cefa-f1a0-4388-87da-f1a6221e3925 |

Після додавання записів перевірити підтвердження домену і TLS через Sites. За потреби сервіс може видати додаткові записи для сертифіката. Не замінювати записи основного домену чи інших субдоменів.

Доступ до сайту наразі приватний; підключення домену саме по собі не змінює аудиторію. Публічний запуск потребує окремої зміни доступу.

На момент підключення браузер Cloudflare відкрив форму входу. Вхід користувачем потрібний для продовження налаштування DNS через кабінет.
